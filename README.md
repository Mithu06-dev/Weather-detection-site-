Weather Detection Website 

A Weather Detection Website is a responsive web application developed using HTML, CSS, and JavaScript that provides real-time weather information for any city entered by the user. The website fetches live weather data from a weather API and displays details such as temperature, humidity, wind speed, weather condition, and location in a clean and user-friendly interface.

The project is designed with an attractive UI using CSS and dynamic functionality using JavaScript. Users can easily search for any city and instantly get updated weather information. This project helps beginners understand API integration, DOM manipulation, asynchronous JavaScript, and responsive web design.

Features:

Real-time weather updates
Search weather by city name
Displays temperature, humidity, and wind speed
Dynamic weather icons based on conditions
Responsive and modern UI design
API integration using JavaScript
Technologies Used:
HTML – Structure of the website
CSS – Styling and responsive design
JavaScript – Fetching API data and interactive functionality

Purpose of the Project:

This project aims to provide accurate weather information through a simple and interactive web interface while improving frontend web development skills and API handling knowledge.
